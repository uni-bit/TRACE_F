# 実装依頼書: 図面にあってモデル化されていないものを全部なくす

宛先: Codex / 発行: Claude(レビュー) / ブランチ: `feat/floor-map-rebuild`

**残っている未収録を分割せず一度に全部潰す。** 完了の定義は「図面に描かれていて
立体化されていない構造が無いこと」で、その状態をゲートで機械的に示せること。

なお、カバレッジゲートと研究棟14Fの追加は先行して着手済み。作業ツリーに既に
入っているならその上に積むこと(`scripts/floorplan/build.py` の検証ステージ、
`config.json` の `coverage` / `pageFurniture`、研究棟の 14F)。

## 原因は2種類ある。混同しないこと

| 種別 | 例 | 何が起きているか | 直す場所 |
| --- | --- | --- | --- |
| **A: 矩形の外** | 7F 屋上庭園、2F 棟間デッキ、4F/6F 連絡通路、1F の未確認分 | クロップにすら入っていない | `masterRect` / 新規対象 |
| **B: フットプリントの外** | **8F 図書館**、各階の廊下・接続部 | クロップには入っているが、手描きのフットプリント多角形でクリップされて消えている | `footprints` |

図書館は座標特定済み。8Fページの「図書館」はページ座標 (1706,1547)、
研究棟マスター矩形内の (1249,404) で、**8Fフットプリントの外**。

## A: 矩形の外にある構造(ページ装飾を除外した実測)

| 対象 | 階 | 未収録インク |
| --- | --- | --- |
| 棟間デッキ(シバウラキッズパーク / フラワーガーデン) | 2F | 48,579 px |
| 屋上庭園 | 7F | 16,380 px |
| 未確認 | 1F | 20,441 px |
| 教室棟↔研究棟の連絡通路 | 4F | 2,492 px |
| 同上 | 6F | 2,339 px |
| 同上 | 5F | 1,585 px |

方針:

- **1棟に属する構造**(屋上庭園など)は、その棟の `masterRect` を広げて取り込む。
  広げて他階に余計なインクが入るなら、その階に `eraserRects` を足す
- **2棟にまたがる構造**(棟間デッキ、連絡通路)は、どの棟にも属さないので
  **独立した対象として `buildings` に登録する**。その構造がある階だけ `pages` に持たせる。
  配置は他棟と同じく「参照ページ座標の差分 × スケール」で決まるので追加の位置合わせは不要
- 連絡部は壁抽出をかけてよいが、**吹き抜け・縦動線・什器のアノテーションは不要**。
  床と壁で足りる
- 1F の 20,441 px はまず正体を確認し、上のどちらかに振り分ける

## B: フットプリントの再実測(全棟・全階)

フロアごとの「インクのうちフットプリント外に落ちる割合」:

| 棟 | 1F | 2F | 3F | 4F | 5F | 6F | 7F | 8F | 9F | 10F | 11F | 12F | 13F | 14F |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 研究棟 | 28% | **33%** | 2% | 23% | 22% | 17% | 16% | **17%** | 1% | 2% | 2% | 10% | 2% | 新規 |
| 本部棟 | 10% | 12% | 2% | 14% | 10% | 11% | 10% | 12% | 0% | 0% | 0% | 0% | 6% | 6% |
| 教室棟 | **24%** | 19% | 13% | 21% | 17% | 11% | | | | | | | | |
| 交流棟 | 7% | 9% | 1% | **18%** | **18%** | 7% | | | | | | | | |

**0〜2% なのは参照階(3F)と個別実測済みの階(研究棟9〜11F・本部棟9〜12F)だけ。**
残りは参照階の `default` を外形の違う階に流用しているため 10〜33% 欠けている。

- 全棟・全階について、その階専用の多角形を実測して `footprints` に追加する
- 計測は `scripts/floorplan/grid_probe.py`。**壁線の芯を取ること**
  (外側を拾うと系統的にずれる。実例あり)
- 目標は **各階 8% 未満**。到達できない階は、残差の正体を報告に書くこと
  (ラベル文字なら可、建物本体なら未解決として残す)
- 既に 0〜2% の階は触らないこと

## 合格条件

- ページ単位ゲート: 全ページで未収録インクが 2,000 px 未満、
  または `coverage.acceptedGaps` に理由付きで登録されている
- フロア単位ゲート: フットプリント外 8% 未満の階が大多数
- **7F に屋上庭園、8F に図書館、2F に棟間デッキ、4F/6F に連絡通路が出る**
- 参照階(全棟3F)と研究棟9〜11F・本部棟9〜12F の生成物が無変更
- `npx tsc --noEmit` / `npx eslint src` / `npm run build`

## 報告に含めるもの

1. `debug/coverage/report.md` のページ単位・フロア単位の表(修正後)
2. A の各対象をどう処理したか(矩形拡張か、新規対象か)
3. B の階別 before/after の割合
4. 8% を切れなかった階と、その残差の正体

## 環境

- `.git` に書けない。**git commit / git add は実行しない**。作業ツリーに残すこと
- ブラウザは使えない。3D の目視確認はレビュー側が行う
- `docs/impl-request-*.md` は変更しないこと
